Masuk admin

Portal ini untuk mengubah isi website Kampung Marga Mulya. Masuk dengan token GitHub milik akun admin yang sudah diberi akses ke organisasi Kampung-Marga-Mulya.

Token hanya disimpan selama tab ini terbuka dan sesi berakhir otomatis setelah 30 menit tanpa aktivitas.

Cara membuat token admin
  1. Pastikan akun GitHub Anda sudah diundang ke organisasi Kampung-Marga-Mulya dengan akses tulis (write).
  2. Buka github.com → Settings → Fine-grained tokens → Generate new token.
  3. Isi nama token, misalnya Admin Website Marga Mulya, dan pilih masa berlaku.
  4. Resource owner: pilih Kampung-Marga-Mulya. Repository access: Only select repositories → kampung-marga-mulya.github.io.
  5. Permissions → Repository permissions → Contents: Read and write. Lalu klik Generate token.
  6. Salin token (diawali github_pat_) dan tempel di kolom di atas. Jangan bagikan token kepada siapa pun.
